# Security Policy

## Reporting a Vulnerability

Please do not disclose security-sensitive issues in public GitHub issues.

If private vulnerability reporting is enabled for this repository, use the repository's **Security** tab to submit a report.

Otherwise, contact the maintainer through the contact options available on GitHub:

https://github.com/ErrorByNight2004

Please include, where possible:

- A clear description of the vulnerability.
- The affected files, endpoints, or features.
- Reproduction steps or a proof of concept.
- The potential impact and any suggested mitigation.

Do not include real users' private records, passwords, API keys, or other secrets in a report.

## Scope

Security issues may include:

- Unsafe handling of personal, session, or journal data.
- Prompt injection or unsafe model-tool behavior.
- Unintended remote access to local services.
- Unsafe file handling or command execution.
- Vulnerabilities in report exports, text-to-speech, or synchronization endpoints.

## Disclosure

Please allow reasonable time for investigation and remediation before publicly disclosing a vulnerability.

The maintainer will assess reports based on severity, reproducibility, and potential impact.
